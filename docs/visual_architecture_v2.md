# ビジュアルアーキテクチャ v2 - ハイブリッド設計

## 根本思想
プリレンダーは「素材」、ランタイムは「演出」。
TV収録と放送の関係。映像自体は事前に作るが、
どの映像をいつ流すかはライブで判断する。

## 3層プロンプトシステム

### Layer 0: 永続（部屋・カメラ）
- 全シーンで同じ: MAO_ROOM, MAO_CHARACTER, STYLE
- カメラアングルはクリップ種別で固定

### Layer 1: 話題単位（小道具）
- 話題ごとのscene（小道具セット）
- 例: 猫 → 猫クッション、猫おもちゃ、猫おやつ
- Flux画像生成時に1回だけ使う

### Layer 2: クリップ単位（アクション）
- 4カテゴリのアクションプロンプト
- ランタイムが状況に応じて選択

## 4カテゴリのクリップ

### talking（話してる時）
- カメラ: クローズアップ正面、カメラ目線
- トリガー: 発話中（autonomous talk / comment response）
- 話題ごとに1本プリレンダー
- 内容: カメラに向かって話す、ジェスチャーする

### activity（沈黙・間の時）
- カメラ: ミッドショット横、カメラ見てない
- トリガー: 発話間の沈黙、思考中
- 話題ごとに1本プリレンダー
- 内容: 話題に関連した行動をしてる

### reaction（コメント受信時）
- カメラ: クローズアップ正面
- トリガー: コメント到着 → 感情判定 → 対応クリップ
- 話題に依存しない共通6本:
  - surprise: 驚き（えっ！まじ？）
  - laugh: 笑い（あはは、ふふ）
  - think: 考え込む（うーん...）
  - nod: 同意（うんうん）
  - shy: 照れ（えへへ）
  - wave: 挨拶（おーい）

### mood（話題切り替え時）
- カメラ: ワイドショット、部屋全体
- トリガー: topic_change
- 話題ごとに1本プリレンダー
- 内容: 部屋の雰囲気、まおは小さく映る

## ランタイム状態マシン

```
[配信開始]
    │
    ▼
┌─────────────┐
│  IDLE       │◄────────────────────┐
│  activity   │                     │
│  クリップ再生│                     │
└──────┬──────┘                     │
       │ 発話開始                    │
       ▼                            │
┌─────────────┐     コメント到着     │
│  SPEAKING   │─────────────┐      │
│  talking    │             │      │
│  クリップ再生│             ▼      │
└──────┬──────┘  ┌──────────────┐  │
       │         │  REACTING    │  │
       │         │  reaction    │  │
       │         │  クリップ再生 │  │
       │         └──────┬───────┘  │
       │                │          │
       │ 発話終了        │ 1-2秒後   │
       └────────────────┴──────────┘
              │
              │ 話題変更
              ▼
       ┌─────────────┐
       │  TRANSITION │
       │  mood       │
       │  クリップ再生│
       └──────┬──────┘
              │ 3秒後
              ▼
         [IDLE に戻る]
```

## WebSocketイベント → クリップ選択

| イベント | 現在のクリップ状態 | アクション |
|---------|-----------------|-----------|
| subtitle | → SPEAKING | talking クリップに切替 |
| comment_event | → REACTING | 感情判定 → reaction クリップ再生 |
| 沈黙 (3秒以上) | → IDLE | activity クリップに切替 |
| topic_change | → TRANSITION | mood クリップ再生 → 新話題のIDLE |

## コメント → リアクション感情マッピング

パイプラインの reflex_layer.py が出す EmotionSpike を使う:
- surprise > 0 → surprise クリップ
- warmth > 0 → shy クリップ
- joy_reflex > 0 → laugh クリップ
- attention > 0 → nod クリップ
- defensiveness > 0 → think クリップ
- デフォルト → wave クリップ

## プリレンダー予算

| カテゴリ | 本数 | 時間見積 |
|---------|------|---------|
| talking (24話題) | 24本 | 24 x 3min = 72min |
| activity (24話題) | 24本 | 24 x 3min = 72min |
| mood (24話題) | 24本 | 24 x 3min = 72min |
| reaction (共通) | 6本 | 6 x 3min = 18min |
| **合計** | **78本** | **~4時間（並列で半減可）** |

クリップ長: 各10秒
ピンポン再生: 10秒 x 2 = 20秒ループ
total映像: 78本 x 20秒 = 26分のユニークコンテンツ
