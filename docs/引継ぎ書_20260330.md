# 引継ぎ書 2026-03-30

## 前回からの主な変更

### 1. Live2D → AI生成キャラクターへの完全移行
- VTube Studioを外し、Flux画像にまおを一体生成する方式に変更
- `MAO_CHARACTER`定数でキャラクター外見を統一（灰茶ロング・赤リボン・クリームカーディガン・セーラー服）
- `MAO_ROOM`定数で部屋を統一（木の床・デスク+ノートPC・本棚・フェアリーライト・窓から都市夜景・ベッド）
- 全27シーン + 27動画アクションプロンプト

### 2. Flux → Kling 動画チェーン
- 話題変更 → Flux画像生成(16s) → 表示せず → Kling img2video(65-120s) → 動画完成時に表示
- `video/image_generator.py`: `_chain_to_video()`で自動連鎖
- 動画専用モード: 画像は表示しない、動画の素材としてのみ使用
- 動画完成まで前の動画がループし続ける

### 3. 「まおの部屋」コンセプト
- 旧: 話題ごとに別世界（宇宙空間、海中、魔法の森...）
- 新: まおの部屋は固定。話題に応じて部屋での行動が変わる
- 例: ゲーム→コントローラー連打、猫→猫と遊ぶ、音楽→ヘッドホンでリズム、料理→キッチンで味見

### 4. PiAPI Creatorプランにアップグレード ($15/月)
- Kling image-to-video が利用可能に
- Motion Brush、Video Extension、Lip Sync、Watermark Removalが解放
- Pay-as-you-goモードで動作中（Host-your-account 0/0）
- クレジット残高: $16.83

### 5. HTTPファイルサーバー追加
- `overlay_server.py`に静的ファイルサーバーを内蔵
- WebSocket: ws://127.0.0.1:8765（状態・字幕・イベント）
- HTTP: http://127.0.0.1:8766（プロジェクト全体を配信）
- OBSブラウザソースはHTTP URLを使用（file://だと動画再生不可）

### 6. 字幕修正
- 旧: 8秒タイマーで消える → 読み終わる前に消える
- 新: 次の字幕が来るまで消えない（タイマー削除）

### 7. OBS構成シンプル化
- 旧: 7-8ソース（VTube、ニューラルコア、感情オーブ、AI HUD、アンビエント背景...）
- 新: 3ソースのみ
  1. 字幕テロップ: http://127.0.0.1:8766/overlay/subtitle.html
  2. メインビジュアル: http://127.0.0.1:8766/overlay/main_visual.html
  3. オーロラ: http://127.0.0.1:8766/overlay/aurora.html

### 8. プリフライト整理
- VTube Studio確認を削除
- overlay確認をsubtitle/main_visual/auroraの3つに
- ImageGenerator確認を追加
- 11チェック体制

### 9. 起動時キャッシュクリア

## 現在の課題

### 最優先: Kling動画化の安定性
- 日中は65-109秒で完了するが、深夜は324秒以上かかりタイムアウト
- タイムアウトを3分→5分に延長済み
- CancelledError対応済み（配信終了時にタスクがキャンセルされても安全）
- 30秒ごとの進捗ログ追加済み
- **次のアクション**: 日中にテスト配信して動画チェーンが完走するか確認

### トピックエンジン修正（未着手）
- DEVELOPフェーズがLLMを過度に制約し、浅い繰り返し発話を引き起こしている
- 提案: トピックエンジンはトピック切り替えタイミングのみ制御し、LLMにはテーマのみ渡して自由生成

### 動画初回表示の待ち時間
- Flux 16s + Kling 65-120s = 約90秒の待ち時間
- その間は前の動画ループ or オーロラ背景
- 改善案: プリキャッシュ（話題リスト生成時に先行して画像/動画を生成）

## 追加更新 (2026-04-03): マルチカメラシステム

### コンセプト変更
「まおの部屋ドキュメンタリー」- TV番組のようにカメラアングルを切り替える。

### 3カメラシステム
| カメラ | 画角 | 視聴者体験 |
|--------|------|-----------|
| A: クローズアップ | 正面、カメラ目線、浅い被写界深度 | ビデオ通話のように語りかける親密感 |
| B: ミッドショット | 3/4アングル、上半身 | 日常を覗く観察の視点 |
| C: ワイドショット | 部屋全体 | 映画的な引き、雰囲気 |

### プロンプトレイヤー構造
```
Layer 0: 永続 - STYLE, MAO_CHARACTER, MAO_ROOM
Layer 1: 話題単位 - scene（小道具）
Layer 2: カット単位 - cam（カメラ）+ pose（ポーズ）+ kling（動画アクション）
```

### プレイリスト再生
- 1話題 → 1 Flux画像 → 3 Klingクリップ（並列生成）
- Clip A完成即再生、B,Cは完成次第プレイリストに追加
- ピンポン再生（順10秒→逆10秒）+ クリップ間クロスフェード
- シャッフル再生で順番が毎回変わる
- 3本 × 20秒(ピンポン) = 60秒ユニーク

### ファイル変更
- `video/image_generator.py` (458行): マルチカメラ24話題×3ショット
- `overlay/main_visual.html` (135行): プレイリスト+ピンポン再生
