### ⚠ 未解決バグ: 話題展開の単調化問題

**症状:**
- DEVELOPフェーズでLLMが「なんかね……○○って、ちょっと気になるよね」を繰り返す
- 1話題あたりINTRO(1) → DEVELOP(同じ文×4) → DECAY(1) → 次の話題、の繰り返し
- 話題が枯渇するとフィラー無限ループに入る（一部修正済み・不完全）

**根本原因分析:**
- 19:24のテスト成功 → `phase=opening | topic=なし`でLLMが自由に話していた
- 20:20のYouTubeテスト成功 → コメントが来てLLMに豊富なコンテキストがあった
- topic_engine制御下のDEVELOPフェーズではプロンプトが制約的すぎる
- DEVELOPのヒント「話題を広げる。3〜5文。」だけではLLMが展開できない
- _conversation_contextに同じ文が蓄積 → 悪循環

**修正方針（次セッションで着手）:**
1. topic_engineのプロンプトヒントを大幅強化
   - DEVELOPで前の発話内容を踏まえた具体的な展開指示を生成
   - 「前回は○○と言った。それを踏まえて別の角度から話す」
2. LLMに渡す会話コンテキスト（_conversation_context）の重複除去
   - 同じ文が2回以上入らないようフィルタ
3. openingフェーズの成功パターンをDEVELOPにも適用
   - topic=テーマだけ与えて、LLMに自由に話させる方式に変更
   - topic_engineは「いつ話題を変えるか」だけ制御する
4. seed_data.jsonから「誰かいるー？」を削除
5. フィラー率の更なる削減（現状でもまだ多い）
