## 技術メモ
- モデル: `claude-sonnet-4-6`（claude-sonnet-4-5は廃止済み）
- `pipeline.py`には必ず`from loguru import logger`が必要
- overlay_serverが`_last_clip`をキャッシュ → 新規接続に再送
- HTTPサーバーはRange Request対応（動画再生に必須）
- `onloadeddata` + `preload="auto"`（`oncanplaythrough`は大動画で発火しない）
- clip_selectorは`video > image`の優先順
- main_visual.htmlはrAF+setInterval(33ms)デュアル駆動
- 【長間】(1500ms以上)の時だけカットアウェイ発火
- カットアウェイ後は`wasVideo`を確認してplayVideo再開
- Fluxマルチフレームモーフィングは空間一貫性なしで棄却
- Kling 5s動画+ピンポン=10s視覚ループ
- PiAPI Kling APIは一時障害あり（500 failed）→復旧済み
- `os._exit(0)`はpyaudio/AivisSpeechのネイティブクラッシュ回避
